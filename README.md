## 🧠 About This Repository

This repository contains a collection of **Verilog and SystemVerilog RTL design and verification experiments** developed as part of a digital design and verification laboratory.

The experiments progress from basic RTL design and simulation to a structured SystemVerilog verification environment containing:

- Transactions
- Randomization
- Mailboxes
- Generator
- Driver
- Monitor
- Scoreboard
- Environment
- Functional verification concepts
- Combinational circuit verification
- Sequential circuit verification
- Waveform analysis

The designs are simulated using **Verilator** and analyzed using **GTKWave**.
